# Verso privacy policy

Public privacy policy for Verso, a Bible reading and language-learning app for Android, served with
GitHub Pages at https://mannygcg.github.io/verso-privacy/.

The source of truth is `privacy-policy.html` in the Verso app repository; `index.html` here is that
page wrapped as a standalone HTML document. Update both together.

`store/screenshots/` holds the current Google Play phone screenshots (1080×2400), recaptured
Oct 8, 2026.
